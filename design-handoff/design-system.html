Handoff para Claude Code

13

Pasos concretos para implementar el sistema sobre el repo actual. Cada paso es atómico y testeable.

Extender tailwind.config.ts con neutros + semánticos

Tu primary ya está bien. Agrega gray (slate ya está en Tailwind por defecto, pero conviene fijarlo), success, warning, danger, info, purple como aliases para no escribir green-100 en código.

Fix kpi-card.tsx · eliminar colores hardcoded

Reemplaza bg-[#e0f2f1] text-[#008080] por bg-primary-50 text-primary-600. También sube el radio del icono a rounded-xl y el tamaño a w-11 h-11 (44×44).

Fix badge.tsx · status Confirmada en teal

En AppointmentStatusBadge, cambia confirmed: { variant: 'info' } → confirmed: { variant: 'primary' }. Agrega variante primary al variantClasses con bg-primary-50 text-primary-700. Cambia no_show a variant default (gris).

Fix upcoming-appointments.tsx · usar tokens

Reemplaza text-[#008080] y text-[#006666] por text-primary-600 y text-primary-700. Reemplaza bg-green-100 text-green-700 por bg-primary-50 text-primary-700 (status confirmed). El status helper duplicado puede usar el AppointmentStatusBadge compartido.

Unificar radios · rounded-xl es default

Cambia rounded-lg → rounded-xl en cards de dashboard y todos los border border-gray-200 bg-white. Botones permanecen en rounded-lg (10px). Pills/badges en rounded-full.

Refactor globals.css · alinear con tokens

La clase .card usa shadow-sm border border-gray-200 p-6. Cámbiala a border border-gray-200 p-5 rounded-xl (sin sombra default, p-5 = 20px). Usa .card-elevated para cuando sí necesites elevación.

Agregar plugin para CSS variables

Para soportar modo oscuro sin duplicar todo, mueve los colores a CSS variables y referénciale desde Tailwind con un plugin (tailwindcss-themer o variables propias en globals.css). Toggle vía data-theme="dark" en <html>.

Nuevos componentes UI que faltan

Empty state (ya hay uno inline en UpcomingAppointments — sácalo a ui/empty-state.tsx) · StatPill (KPI inline con delta vs período anterior) · Toast (notificación tras acción) · SegmentedControl (día / semana / mes en calendario) · Tabs.

Mobile-first audit

Tu sidebar ya tiene -translate-x-full en móvil. Falta: bottom-nav para vista de empleado (mejor que sidebar lateral en móvil) y safe-area-inset-bottom en sticky bottoms (ya tienes .safe-bottom, úsalo). Tamaño mínimo de hit area en móvil: 44×44px.
